# Assistente Digital de Vestuário – ANAMS 2026/27 (Grupo 1)

Trabalho prático de Análise e Modelação de Sistemas (LES – ISEP), Iteração 1.

Aplicação de consola em Java (Maven) que ajuda os utilizadores a escolher as peças de roupa a usar em diferentes situações.

## Estrutura
- `org.UI` – interfaces com o utilizador (menus e UI de cada caso de uso)
- `org.Controller` – controladores dos casos de uso (padrão Controller)
- `org.Model` – classes do domínio (`AssistenteVestuario`, `Cor`, `Ocasiao`, `Estacao`, ...)
- `org.Utils` – classes utilitárias fornecidas (`Data`, `Utils`)

## Executar
Classe principal: `org.UI.Main`.
